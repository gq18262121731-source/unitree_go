Go2 UWB伴随实时监测——模拟展示包
==================================

用途
----
本软件用于在没有 Go2 真机和项目源码的 Windows 电脑上展示比赛界面。
界面使用内置模拟数据，并会显著显示“模拟数据”。它不会连接机器人，也不会发送任何运动命令。

启动
----
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“启动UWB模拟演示.bat”。
3. 稍等片刻，默认浏览器会自动打开：
   http://127.0.0.1:8050
4. 浏览器中按 F11 可进入全屏展示。

停止
----
回到启动程序的黑色窗口，按 Ctrl+C；也可以直接关闭该窗口。

常见问题
--------
1. 浏览器未自动打开：手动访问 http://127.0.0.1:8050
2. 提示端口被占用：先关闭上一次运行的程序，再重新启动。
3. Windows 安全提示：该程序是本地生成的未签名演示程序，可选择“更多信息”后运行。

运行环境
--------
Windows 10/11 64 位。目标电脑不需要安装 Python、Dash 或项目依赖。
