## Wireshark Capture Procedure

Use Wireshark on Windows with Administrator privileges.

1. Select the WLAN adapter whose local IP is `192.168.8.240`.
2. Start capture.
3. Keep Go2 online on the mobile WiFi network.
4. Run the read-only DDS subscription script.
5. Wait 30 to 60 seconds.
6. Stop the DDS script.
7. Stop capture.
8. Review traffic by source IP, protocol, and port.

Read-only script:

```powershell
python tools\dds_diagnostics.py --interface WLAN --domain-id 0 --peer 192.168.8.235 --timeout 10
```

Initial Wireshark filters:

```text
ip.addr == 192.168.8.235
```

```text
ip.addr == 192.168.8.235 && udp
```

DDS/RTPS filters:

```text
ip.src == 192.168.8.235 && rtps
```

```text
ip.src == 192.168.8.235 && udp.port >= 7400 && udp.port <= 7500
```

Optional multicast check:

