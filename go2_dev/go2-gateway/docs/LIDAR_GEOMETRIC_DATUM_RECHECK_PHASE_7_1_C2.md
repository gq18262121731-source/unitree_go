# Phase 7.1-C2 LiDAR 几何基准复核

状态：`GEOMETRY_REPEATABLE_THRESHOLD_CALIBRATION_HOLD`  
约束：只读、机器人静止、真实运动关闭

## 目标

区分现有约 `+0.11～+0.17 m` 测距偏差来自：

1. 人工测距起点与 `base_link` 原点不一致；或
2. `cloud_base` 几何/外参或障碍反射面存在偏差。

本阶段不改 SafetyGuard 阈值，不写入 ROI 参数，不启动运动。

## 离线基准发现

本地 Go2 URDF 的 `base` 坐标具有以下几何关系：

```text
前髋关节轴 x = +0.1934 m
后髋关节轴 x = -0.1934 m
base 原点       = 前后髋关节轴中点
机身碰撞盒长度  = 0.3762 m
碰撞盒前沿      = base 原点前方约 0.1881 m
```

因此，如果人工距离从机身前沿开始量，而点云距离从机身中心原点开始量，理论上会产生约 `+0.188 m` 的正偏差，方向和当前观测一致。

但该 URDF 的 link 名称是 `base`，固件 `cloud_base` 的 frame 是 `base_link`；仓库没有给出二者的官方等价声明，且既有 `radar_joint` 与设备实测不匹配。因此上述位置只能作为现场复核候选，不能作为官方外参结论。

现场操作者已确认此前正式测量就是从前后髋轴中心线的纵向中点向地面的投影开始。因此“误从前壳起量”不再作为当前偏差解释。

代码核对还确认 SafetyGuard 使用水平径向距离 `hypot(x, y)`，没有把 `z` 高度计入距离。正式样本中该径向计算相对前向 `x` 仅增加约 6–12 mm，不能解释 0.11–0.17 m 偏差。

历史 raw cloud 与 `cloud_base` 配对反求得到固定变换平移约
`[0.282160, 0, 0] m`，内部残差小于 1.5 μm。这证明固件转换稳定，
但仍不构成外部物理原点准确性的标定。当前剩余主要假设为：

1. 障碍物标称位置与 LiDAR 实际反射面不一致；
2. 障碍平面未垂直/未居中，最近稳定点落在其他表面；
3. `cloud_base` 的物理原点相对实体中点存在固定偏置。

## 测量基准

现场已按以下方式确认机器人机身纵向中心基准：

```text
前髋左右轴中心连线
后髋左右轴中心连线
两条连线的纵向中点
```

将该中点垂直投影到地面，记为 `DATUM_CONFIRMED_BASE_CENTER`。禁止从以下位置起量：

- 前壳；
- 头部/摄像头外壳；
- LiDAR 外壳；
- 前脚或腿；
- 随机器人姿态变化的部件。

障碍物必须改用宽而平整、垂直于机器人 x 轴的刚性参考平面。距离量到最靠近机器人的有效反射面，而不是支架、底座或物体中心。先只复测 1.20 m；该点可重复后再开展其余三点。

## 四点复测

保持同一机器人姿态、同一基准标记和同一障碍平面，只测试：

```text
1.20 m
0.80 m
0.65 m
0.50 m
```

每个位置至少采集 30 个连续点云，记录：

- 实际卷尺/激光测距值；
- 点云最近距离 min/median/max；
- CLEAR/SLOW/STOP；
- ROI 点数；
- frame、频率、解码错误；
- `motion_calls=0`。

验收参考：

```text
|median_lidar_distance - measured_from_datum| <= 0.10 m  优先目标
<= 0.15 m                                               最大容许
0.65 m 和 0.50 m                                       稳定 STOP
```

如四点仍呈近似固定偏差，先检查基准和反射面；不得直接向软件写入固定 offset。

## `roi_min_z=-0.25 m` 低矮障碍复验

`-0.25 m` 仍是运行时候选值。除空场 CLEAR 外，必须用定义明确的低矮、宽幅刚性障碍验证不会漏检，并记录障碍高度、宽度、距离和 ROI 点数。测试对象不得小到低于本项目未来明确规定的最小可检障碍规格。

至少覆盖：

```text
低矮障碍 @ 0.80 m -> 不得 CLEAR
低矮障碍 @ 0.50 m -> 必须 STOP
```

若候选 z 下出现危险 CLEAR，则候选参数失败，生产默认继续保持 `-0.35 m`，Phase 7.2 继续关闭。

## Gate

只有同时满足以下条件，才可提出冻结 LiDAR 参数的申请：

- 测距基准可复现并记录；
- 四点误差均不超过 0.15 m；
- 0.65 m、0.50 m 稳定 STOP；
- 候选 ROI 空场无持续误报；
- 候选 ROI 不漏检规定的低矮障碍；
- 全程 `motion_calls=0`。

完成 C2 仍不自动开放运动。Phase 7.2 必须另行人工批准。
