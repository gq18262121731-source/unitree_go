# Go2 无线视频 RTMP 服务端接入说明

## 1. 当前视频源

Go2 EDU 已通过 STA-L 无线网络接入桥接电脑，当前链路为：

```text
Go2 内置摄像头
    -> WebRTC / Wi-Fi
桥接电脑
    -> 本地 MJPEG
FFmpeg
    -> RTMP 推流
流媒体服务器
    -> HLS / HTTP-FLV / WebRTC
社区端或后台页面
```

当前已经验证：

| 项目 | 当前值 |
| --- | --- |
| Go2 无线地址 | `192.168.8.248` |
| 桥接电脑地址 | `192.168.8.251` |
| 无线网络 | `E5576-822_D7E5` |
| 本地预览 | `http://127.0.0.1:8093/` |
| 本地 MJPEG | `http://127.0.0.1:8093/stream.mjpg` |
| 分辨率 | `1280x720` |
| 视频编码输出 | 建议 H.264 |
| 音频 | 第一阶段不传输 |

## 2. 需要服务端提供的信息

请流媒体服务端负责人提供以下内容：

### 2.1 完整 RTMP 推流地址

必须提供可以从桥接电脑直接访问的完整地址，格式示例：

```text
rtmp://服务器域名或IP:1935/live/go2-edu-001
```

其中：

- `服务器域名或IP`：公网域名、公网 IP 或同一局域网内可访问的服务器地址；
- `1935`：RTMP 默认端口，若服务端使用其他端口请明确说明；
- `live`：流媒体应用名称；
- `go2-edu-001`：机器狗对应的流名称或推流密钥。

最终需要提供的是一个可以直接使用的完整值，例如：

```text
RTMP_URL=rtmp://media.example.com:1935/live/go2-edu-001
```

### 2.2 鉴权方式

请说明推流是否需要鉴权：

- URL 中附带推流密钥；
- 用户名和密码；
- URL 查询参数签名；
- IP 白名单；
- RTMPS 证书或其他安全要求。

不要把真实密码、Token 或永久密钥写入公开文档或 Git 仓库。

### 2.3 网页播放地址

RTMP 主要用于推流，普通浏览器不能直接播放 RTMP。服务端还需要返回至少一种网页播放地址：

```text
HLS:       https://media.example.com/live/go2-edu-001.m3u8
HTTP-FLV:  https://media.example.com/live/go2-edu-001.flv
WebRTC:    https://media.example.com/webrtc/go2-edu-001
```

展示优先时可使用 HLS 或 HTTP-FLV；需要更低延迟时建议提供 WebRTC 播放地址。

### 2.4 网络和防火墙

服务端需要确认：

- 桥接电脑能够访问 RTMP 主机和推流端口；
- 服务端防火墙和云安全组已开放对应入站端口；
- 播放域名、HTTPS 证书和跨域策略可供社区端页面使用；
- 若使用公网 IP，应确认运营商网络没有阻断推流端口。

## 3. 建议的第一阶段推流参数

```text
视频编码：H.264
分辨率：1280x720
帧率：10-15 FPS
码率：1500-2500 kbps
关键帧间隔：2 秒
音频：关闭
封装格式：FLV
```

桥接电脑上的输入地址：

```text
http://127.0.0.1:8093/stream.mjpg
```

Windows FFmpeg 推流命令示例：

```powershell
ffmpeg -hide_banner -loglevel info `
  -f mjpeg -framerate 10 `
  -i "http://127.0.0.1:8093/stream.mjpg" `
  -an -vf "fps=10,scale=1280:720" `
  -c:v libx264 -preset veryfast -tune zerolatency `
  -b:v 1800k -maxrate 2200k -bufsize 3600k `
  -g 20 -pix_fmt yuv420p -f flv `
  "rtmp://服务器地址:1935/live/go2-edu-001"
```

## 4. 服务端返回信息模板

请服务端按以下格式返回：

```text
RTMP 推流地址：
推流端口：
鉴权方式：
流名称/设备标识：go2-edu-001
HLS 播放地址：
HTTP-FLV 播放地址：
WebRTC 播放地址：
管理后台地址：
测试有效期：
联系人：
```

## 5. 联调验收标准

第一阶段按以下指标验收：

1. 桥接电脑能够成功连接 RTMP 服务端并持续推流；
2. 服务端能够识别 `go2-edu-001` 为在线流；
3. 社区端或后台页面能够播放 Go2 第一视角画面；
4. 连续播放 15 分钟，采集和推流服务不退出；
5. 无频繁断流、黑屏或长时间画面停顿；
6. 推流停止后，服务端能够正确更新设备离线状态。

## 6. 当前待提供项

当前本地无线视频源已经正常，现阶段唯一缺少的服务端参数是：

```text
完整 RTMP_URL
至少一个网页播放 URL
对应的鉴权信息
```

收到以上参数后，即可开始 Go2 无线视频公网或局域网推流联调。
